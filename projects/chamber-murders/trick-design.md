## 一、核心诡计概述

### 谜面（读者看到的表象）

暴雨将六名高中生困在阿巴拉契亚山区偏僻的废弃 lodge——"**Ravenwood Lodge**"。手机没有信号，山路被泥石流截断。当夜，一名学生被发现死在自己反锁的房间里——门从内侧插着老式铁栓，窗户的铁插销也从内侧锁死。房间里没有任何外人进出的痕迹。

第二天，又一名学生死亡。

Lodge 有一个恐怖传说：三十年前有位客人在暴风雨夜离奇死亡，此后每逢风雨夜就有人看到他的影子在走廊游荡……活着的学生开始相信：杀人的不是人，是这座 lodge 本身。

### 谜底（真实发生的事情）

凶手是六名学生中最受信赖的一人——**这次旅行的组织者 Ethan Cross**。他曾在一年前独自来过这座 lodge，熟悉建筑结构。他知道 lodge 二楼房间外侧有一条相连的**石质装饰檐台**（宽约 30cm），可以沿外墙从一个房间的窗户攀越到另一个房间的窗户。所有"超自然现象"都是凶手事先布置或临场制造的心理战。

### 诡计机制（密室如何形成）

```
密室制造步骤：

1. 凶手等到深夜，确认目标独自回房并锁门入睡
2. 凶手从自己房间的窗户翻出，沿二楼外侧石檐攀至目标房间窗外
3. 用事先准备的薄铁片从窗缝外侧拨开老旧的窗户插销（铁插销有磨损间隙）
4. 进入房间，杀死受害者（窒息，安静且不留血迹）
5. 布置现场，制造"睡梦中死亡"的假象
6. 从窗户原路翻出
7. 用同一根铁丝/薄片从外侧将窗户插销重新推回锁死位置
8. 沿石檐返回自己房间

结果：门从内侧反锁（受害者自己锁的），窗户插销也在内侧锁死位置
     → 完美密室
```

**超自然假象的制造手段**：

| 现象 | 真相 | 目的 |
|------|------|------|
| 走廊传来脚步声 | 凶手在外侧石檐移动时脚步通过墙壁传声 | 伪装为"鬼魂"活动 |
| 灯光忽明忽暗 | Lodge 电力系统老旧，凶手找到配电箱并操控 | 制造恐怖氛围 |
| 墙壁渗出"血水" | Lodge 墙体受潮后铁锈溶解流出红棕色水渍 | 巧合——但凶手刻意引导解读 |
| "鬼魂日记"出现 | 凶手上次来时藏在 lodge 角落的道具 | 强化超自然叙事、引导恐惧 |
| 房间里出现不明湿脚印 | 凶手从窗户进入时雨水留痕，用布擦除但遗漏微量 | （非故意——这是线索） |

## 二、公平性验证

### Knox 十诫检查（密室推理适用项）

| 编号 | 条目 | 本作合规情况 | 说明 |
|------|------|------------|------|
| #1 | 犯人必须在前30%出现 | ✅ 合规 | 凶手是六人之一，第 1 章即登场 |
| #2 | 不可使用超自然手段 | ✅ 合规 | 所有超自然现象均有理性解释；超自然只是氛围和误导 |
| #3 | 不可有秘密通道（除非暗示） | ⚠️ 需处理 | 石质檐台不是"秘密"——它在建筑外部可见。需在前文安排角色注意到它的存在 |
| #4 | 不可使用未知手段 | ✅ 合规 | 窒息杀人 + 铁片撬窗锁，均为常识范围内 |
| #6 | 不可靠偶然发现破案 | ✅ 合规 | 主角通过观察与推理发现真相 |
| #7 | 侦探不可是犯人 | ✅ 合规 | 主角不是凶手 |
| #8 | 线索必须展示给读者 | ✅ 合规 | 所有线索在正文中出现，详见第三节 |
| #10 | 替身/双胞胎须暗示 | N/A | 不涉及 |

### Knox #3 处理方案

石质檐台的存在必须在密室发生**之前**让读者有机会注意到：
- **第 1-2 章**：学生到达 lodge 时，有人从外面观察建筑，提到"二楼窗户下面有一圈石头装饰"（以建筑描写的方式自然带出，不刻意强调）
- **第 2 章**：角色在二楼向窗外看时，提到窗台外的石檐很窄、看起来年久失修
- 这两处描写让侦探读者回看时能说"原来那个石檐就是关键"

### 密室公平性特殊检查

| 检查项 | 状态 |
|--------|------|
| 密室的物理解法在现实中可行？ | ✅ 30cm 石檐可供攀爬（凶手是体能好的学生） |
| 读者能从线索推理出解法？ | ✅ 石檐 + 窗锁痕迹 + 湿脚印 = 完整推理链 |
| 密室制造不需要专业工具？ | ✅ 铁片/细铁丝，lodge 中可找到 |
| 重锁机制物理上可行？ | ✅ 老式铁插销有磨损间隙，可从缝隙外侧操作 |

### 双读者验证

| 读者类型 | 期望体验 |
|----------|----------|
| 天真读者 | 被超自然氛围带跑，怀疑"鬼魂说"或怀疑错误嫌疑人。揭示时感到"震惊但回想起来线索都在" |
| 侦探读者 | 注意到石檐描写 + 窗户痕迹 + 凶手对 lodge 的异常熟悉。揭示前半步猜到"从窗外进去的"，但可能没猜对凶手身份 |

## 四、诡计可行性分析

### 物理可行性

| 检查项 | 分析 | 结论 |
|--------|------|------|
| 石檐承重 | 30cm 宽的老式石质装饰檐台，建筑外墙一体结构，可承受一个青少年体重 | ✅ 可行 |
| 攀爬距离 | 房间间距约 3-5 米，石檐连续无断裂（二楼外侧装饰带） | ✅ 可行 |
| 暴风雨中攀爬 | 危险但不是不可能——凶手有强烈动机且体能好 | ✅ 可行（体现疯狂决心） |
| 窗锁操作 | 老式铁插销因年久磨损，插销头与槽之间有 2-3mm 间隙，用薄铁片从外侧缝隙可拨动 | ✅ 可行（需前文暗示窗锁老旧） |
| 无痕杀人 | 窒息（枕头闷杀）——安静、不留武器、不产生血迹 | ✅ 可行 |
| 时间窗口 | 深夜 2-4 点，所有人熟睡，暴雨掩盖攀爬声 | ✅ 可行 |

### 心理可行性

| 检查项 | 分析 |
|--------|------|
| 凶手动机强度 | 为死去/受伤的至亲好友复仇——对青少年来说是极强的情感驱动 |
| 凶手伪装能力 | Ethan 是团体中最被信赖的人，长期扮演"好人"角色。内心的愤怒被精心压抑 |
| 凶手预谋深度 | 选择这个地点、组织这次旅行、事先踩点、准备工具、研究 lodge 传说——高度预谋 |
| 为什么选择密室 | 制造超自然恐慌 → 瓦解群体信任 → 为后续作案创造条件。密室不仅是手法，是心理战的武器 |

### 信息控制可行性

| 读者可能的质疑 | 预设回应（在文本中自然处理） |
|---------------|---------------------------|
| "为什么不检查窗户？" | 有人检查了——插销是锁着的。划痕太细微，恐慌中没人细看 |
| "石檐那么危险，凶手不怕摔死？" | 这恰恰说明凶手动机之强烈。可在揭示时让主角感叹"他连命都不要了" |
| "为什么没人听到攀爬声？" | 暴雨 + 雷声完美掩盖。且凶手移动的声音被群体解读为"鬼魂脚步" |
| "凶手怎么知道窗锁能撬？" | 去年来过时就检查过。C03（对 lodge 的异常熟悉）是伏笔 |

## 五、反派计划骨架（James Frey 反派引擎法）

### 反派的完整计划

```
【前史】
一年前，凶手 Ethan Cross 的发小 Mia Lawson 因为被这群学生中的
Jake Morrison 和 Amber Wells 欺凌/排挤/造谣而自杀未遂，严重心理创伤。
学校和涉事学生选择了掩盖和沉默。Ethan 独自承受失去挚友的痛苦，
在沉默中计划复仇。

【计划步骤】
Step 0：踩点（一年前）
  行动：独自来到 Ravenwood Lodge 考察
  留下的痕迹：lodge 登记簿上的签名 → 线索 S03
  发现：石檐路径、窗锁弱点、lodge 传说、配电箱位置

Step 1：组局（旅行前 2 周）
  行动：以"学年末旅行"为名组织同学到 Ravenwood Lodge
  留下的痕迹：选择偏僻地点的不自然性（但被包装为"探险"）
  侦探发现方式：回想时觉得地点选择太过刻意

Step 2：制造超自然恐慌（到达当晚）
  行动：利用配电箱制造灯光闪烁、在走廊制造声响、
       "发现"事先藏好的"鬼魂日记"
  留下的痕迹：C04（超自然现象与凶手行踪的时间关联）
  目的：建立"这个地方闹鬼"的心理预期

Step 3：第一次杀人——密室杀人（第二晚深夜）
  行动：沿石檐攀至受害者 1 窗外 → 撬窗进入 → 窒息杀人 →
       布置现场 → 重锁窗户 → 沿石檐返回
  留下的痕迹：
    - C01：窗户插销外侧划痕
    - C02：石檐灰尘扰动
    - S01：凶手手指擦伤
    - 残留微量湿脚印（被凶手大部分擦除，但角落遗漏）
  侦探发现方式：仔细检查密室时注意到窗锁异常

Step 4：加速群体瓦解（密室发现后）
  行动：引导群体怀疑最可疑的人（幸存者 A），
       同时扮演"冷静调解人"角色稳固自身信任
  留下的痕迹：C03 持续强化（太冷静、太熟悉环境、太会引导话题）
  反击方式：当主角试图理性分析时，凶手用"我们应该先确保安全"
          转移讨论方向

Step 5：第二次杀人（第三天）
  行动：利用群体分裂的混乱时刻作案。
       当部分人去指控幸存者 A 时，凶手与受害者 2 独处并下手
  留下的痕迹：不在场证明有漏洞（声称去取水/找东西）
  目的：进一步强化恐慌，逼近最终目标

Step 6：终局计划（被主角阻止）
  行动：计划在最后一晚杀死真正的目标（最初事件的核心责任人）
  被阻止方式：主角拼合所有线索，识破凶手身份，
            在最后一刻阻止了第三次杀人
```

### 反派的竞争叙事

```
凶手想让所有人相信的版本：
  "这个 lodge 有诅咒。超自然力量在杀人。我们只能各自躲好、祈祷天亮。"

  → 这个叙事的目的：让群体分散（更容易各个击破）、
    不去寻找人为证据、不做理性分析

主角逐渐建立的版本：
  "这些都是人做的。有人在利用我们的恐惧。我们必须一起面对。"

  → 这个叙事的目的：让群体团结、寻找真实证据、
    通过合作而非怀疑来保护彼此
```

## 七、反转设计

### 主反转：身份反转 + 动机反转（L2+L3）

```
读者的预期演变：
  ch1-2：没有明确嫌疑人（超自然氛围主导）
  ch3-4：怀疑幸存者 A（红鲱鱼生效）
  ch5-6：A 被排除，转向其他人
  ch7：  主角缩小范围，但凶手仍不是首选嫌疑
  ch8：  揭示凶手 = 最被信赖的人 → 身份反转
        揭示动机 = 为挚友复仇 → 动机反转

反转类型：「心碎型」—— "怎么会是他..."
情感准备：前文必须让读者真心信赖凶手角色（Ethan 是第一个站出来安慰别人的、
         第一个提出保护计划的、最冷静最可靠的人）
```

### 小反转：受害者关联反转

```
第 8 章揭示：受害者们并非随机——他们是当年欺凌/伤害凶手挚友的直接责任人。
看似无辜的受害者其实有着不堪的过去。

效果：读者对受害者的同情产生裂缝，对凶手的情感态度变得复杂
     → 升华主题："恐惧与怀疑是杀人凶器"——但凶手的痛苦也是真实的
```
