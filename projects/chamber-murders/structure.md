## 一、结构选择与论证

### 所选结构模型

**悬疑三幕式（密室推理变体）** + **MICE 嵌套**

### 为什么这个故事适合这个结构

| 结构特征 | 本作适配 |
|----------|---------|
| 密室推理要求第一幕用 30% 篇幅建立空间 | ✅ 8 章中 ch1-2 专注空间/氛围/角色建立（25%） |
| 密室推理的中点通常是"密室不是我们以为的那种密室" | ✅ ch6 中点——从"超自然密室"翻转为"有计划的连环杀人" |
| 密室揭示分两层：先"怎么做到的"（机制），再"为什么"（动机） | ✅ ch8 先展示石檐路径→再揭示 Mia 的故事 |
| 短篇 30,000 字适合线性单 POV | ✅ 全程 Nora Hartley 第三人称有限视角 |
| 封闭空间天然形成 MICE-M 框架 | ✅ 进入 Lodge → 事件 → 离开 Lodge，环境线程包裹一切 |

### 三幕比例

```
第一幕（建立与卷入）：ch1-2  ≈ 7,000 字（23%）
第二幕上半（调查与表面）：ch3-4  ≈ 8,000 字（27%）
第二幕下半（复杂化与危机）：ch5-6  ≈ 7,500 字（25%）
第三幕（揭示与解决）：ch7-8  ≈ 8,500 字（28%）
                              ─────────────
                       总计 ≈ 31,000 字
```

> 第三幕比经典比例略重（28% vs 25%），因为密室推理的揭示需要完整展示机制 + 动机双层反转 + 情感落点。

## 二、MICE 嵌套结构

```
[M] 被困 Ravenwood Lodge ───────────────────────────────────── 暴雨停·离开
 │ [I] 核心谜团：谁是凶手？密室如何形成？ ──────────────────── Ethan 被揭示
 │ │ [C] Nora 弧光：旁观者 → 行动者 ─────────────────── 主动站出对抗
 │ │ │ [I] 次级谜团α：超自然现象是真的吗？ ────── 全部人为 (ch7)
 │ │ │ [I] 次级谜团β：Dylan 是凶手吗？ ───── 洗清 (ch6)
 │ │ │ [E] 第二次杀人事件 ──── 事件消化 (ch6)
 │ │ └──────────────────────────────────────────── Nora 转变 (ch8)
 │ └───────────────────────────────────────────────── 真相揭示 (ch8)
 └─────────────────────────────────────────────────────── 离开 (ch8 尾声)

关闭顺序（括号法则——先开后关）：
  打开：M → I(核心) → C → I(α) → I(β) → E
  关闭：E → I(β) → I(α) → C → I(核心) → M
```

## 三、三幕式（密室推理变体）适配

### 第一幕 · 建立与卷入（ch1-2 · 0-23%）

**功能**：建立封闭空间、介绍全部角色、制造超自然恐慌、埋设早期线索

| 节拍 | 位置 | 本作对应 |
|------|------|---------|
| 开场意象 | ch1 首段 | 暴雨中的山路——车窗外模糊的 Ravenwood Lodge 轮廓 |
| 日常世界 | ch1 前半 | 六人在车上的互动，建立社交关系和性格 |
| 空间建立 | ch1 后半 | 到达 Lodge，内外描写。**石檐首次出现**（Knox #3） |
| 催化暗示 | ch2 前半 | 超自然现象集中爆发，恐怖传说讲述 |
| 第一幕转折 | ch2 末 | Jake Morrison 没有出现在早餐桌上——不祥的预兆 |

**第一幕完成检查**：
- [x] 六名角色全部登场，关系网初步建立
- [x] Lodge 空间完整呈现（含石檐、窗锁、配电箱等关键地理）
- [x] 超自然氛围建立（走廊脚步声、灯光闪烁、"鬼魂日记"）
- [x] S03（Ethan 提到来过山里）+ C03 初次（Ethan 熟悉 Lodge）已埋设
- [x] Nora 的旁观者性格已展示（观察但不行动）
- [x] 读者产生"这个地方有什么不对"的预感

### 第二幕上半 · 调查与表面假设（ch3-4 · 23-50%）

**功能**：核心谜团建立，表面调查，错误假设形成，线索收集

| 节拍 | 位置 | 本作对应 |
|------|------|---------|
| 催化事件 | ch3 开篇 | 发现 Jake 死在密室中——门窗全部反锁 |
| 首要嫌疑 | ch3 后半 | Dylan 行踪不明 + 与 Jake 有冲突 → 红鲱鱼生效 |
| 调查/乐趣 | ch4 全篇 | Nora 独自调查——窗外石檐灰尘、Ethan 手伤、群体分裂 |
| 错误假设固化 | ch4 末 | 群体多数人锁定 Dylan 为凶手 |

**中点前读者心理预期**：
- 天真读者："Dylan 就是凶手——他和 Jake 有矛盾，又行踪不明"
- 侦探读者："密室手法还没解释。Ethan 对 Lodge 太熟悉了"

### 中点逆转（ch5 末 - ch6 · 50%）

**类型**：案件升级 + 受害者翻转

```
中点前认知：这是一起因个人恩怨导致的密室杀人（超自然 or Dylan 做的）
中点后认知：这是有预谋的连环杀人——凶手不是 Dylan，另有其人
           受害者 Jake 和 Amber 并非无辜——他们曾伤害过某人
```

### 第二幕下半 · 复杂化与危机（ch5-6 · 50-63%）

**功能**：群体瓦解，第二次杀人，红鲱鱼消解，嫌疑方向翻转

| 节拍 | 位置 | 本作对应 |
|------|------|---------|
| 群体瓦解 | ch5 | Ethan 提出分散方案，群体隔离——凶手创造作案窗口 |
| 反派再击 | ch5 末 | Amber 被杀（群体分裂的直接后果——**反主题生效**） |
| 假设崩塌 | ch6 | Sophie 证明 Dylan 清白；Dylan 洗清，嫌疑真空 |
| 信息转折 | ch6 末 | 发现 Jake/Amber 手机中提到"Mia"——新的谜团浮现 |

### 第三幕 · 揭示与解决（ch7-8 · 63-100%）

**功能**：线索串联、灵魂黑夜、真相揭示、主题升华

| 节拍 | 位置 | 本作对应 |
|------|------|---------|
| 灵魂黑夜 | ch7 前半 | Nora 回忆起自己曾见过 Mia 被欺负却没有行动——自我愧疚 |
| 突破口 | ch7 中 | Nora + Sophie 合作：时间线回溯 → 石檐粉末 → Mia 的画 → 指向 Ethan |
| 最终抉择 | ch7 末 | Nora 必须在 Ethan 对 Sophie 动手前站出来——**被动者不得不行动** |
| 高潮/揭示 | ch8 前半 | 对峙 → 推理展示（石檐路径+窗锁机制）→ Ethan 不否认 |
| 动机揭示 | ch8 中 | Ethan 讲述 Mia 的完整故事——情感高潮。"Do you even remember her?" |
| 余波 | ch8 末 | 暴雨停。救援到来。四个人的沉默。Nora 不再是旁观者 |

## 四、章节大纲

### Ch1 · 到达（Arrival）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley（第三人称有限） |
| 地点 | 山路 → Ravenwood Lodge 外 → Lodge 内部 |
| 时间 | Day 1，下午 → 傍晚 |
| 核心功能 | 空间建立 · 角色介绍 · 基调奠定 |
| 字数目标 | ~3,500 字 |
| 张力类型 | 🟢🟡（低→中） |

**核心事件**：
1. 六人乘车前往阿巴拉契亚山区，车内互动展示人物关系（Ethan 开车/组织者地位、Jake 的玩笑、Dylan 的沉默、Amber 的八卦、Sophie 的冷静、Nora 的旁观）
2. 到达 Ravenwood Lodge——外部描写时自然带出**二楼窗户下一圈石质装饰檐台**（Knox #3 首次埋设，以建筑描写方式呈现）
3. Ethan 对 Lodge 异常熟悉——知道备用钥匙位置、哪个房间暖和、配电箱在哪。自然解释"去年暑假在这附近住过"（**S03 + C03 首次**）
4. 暴雨骤降，手机信号全无，山路被泥石流截断——与外界完全隔绝
5. 傍晚分配房间，各自安顿。Nora 用速写本画 Lodge 布局（角色特色展示）

**章末钩子**：深夜，走廊灯光忽明忽暗。远处传来缓慢的脚步声。所有人的房门都关着。

**创作备注**：
- 线索操作：植入 S03、C03 初次
- 嫌疑指向：无（尚无案件）
- 读者此刻推理状态："这个地方有点阴森，但应该只是氛围"
- 空间描写重点：Lodge 整体布局、二楼走廊、房间结构、窗户样式、石檐外观

### Ch2 · 鬼夜（The Haunting）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | Lodge 二楼走廊 · 公共大厅 · Nora 房间窗前 |
| 时间 | Day 1 深夜 → Day 2 清晨 |
| 核心功能 | 超自然氛围建立 · 恐怖传说引入 · 空间深化 |
| 字数目标 | ~3,500 字 |
| 张力类型 | 🟡🔴（中→高） |

**核心事件**：
1. 深夜集体经历"超自然现象"——灯光闪烁（配电箱操控）、走廊脚步声（石檐移动传声）、墙壁渗出红棕色水渍（铁锈，但被解读为"血"）
2. 众人聚到大厅，Ethan 第一个站出来安慰大家、保持冷静（**信赖形象建立**）
3. 角落里发现一本泛黄的"鬼魂日记"——记载三十年前一位客人在暴风雨夜死在密室中（**H02 激活**——实为 Ethan 上次藏的道具）
4. Nora 回房后从窗户向外看暴雨——视线扫过窗台外的石檐，"看起来很窄，年久失修"（**Knox #3 第二次呈现**）
5. **C04 首次**：回忆中，Nora 模糊意识到超自然现象发生时 Ethan 不在身边——但这个念头被恐惧淹没

**章末钩子**：清晨。大家陆续来到餐厅。Jake Morrison 没有出现。有人去敲他的门。没有回应。门从里面锁着。

**创作备注**：
- 线索操作：植入 H02、C04 首次
- 嫌疑指向：无（超自然叙事主导读者注意力）
- 读者此刻推理状态："可能真的闹鬼？那个传说太巧合了"
- 凶手叙事强度：★★★（超自然框架建立）

### Ch3 · 密室（The Locked Room）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | Jake 的房间（密室现场）→ 公共大厅 |
| 时间 | Day 2 上午 |
| 核心功能 | **催化事件** · 核心谜团建立 · 首要嫌疑激活 |
| 字数目标 | ~4,000 字 |
| 张力类型 | 🔴（高） |

**核心事件**：
1. 撞开 Jake 的房门——他死在床上，面色青紫（窒息）。门从内侧插着铁栓，窗户铁插销也在锁死位置
2. **群体震惊**。Amber 尖叫，Sophie 发抖，Dylan 后退。Ethan 第一个冲进去查看——表现出悲痛和控制
3. Nora 在恐慌中仍注意到窗户插销外侧有**极细微的金属划痕**（**C01——情感遮蔽**：发现尸体的冲击淹没了这个细节）
4. 有人指出：昨晚 Dylan 行踪不明——他没和大家一起待在大厅（**H01 激活**）
5. Jake 和 Dylan 两周前在学校当众争吵的事被提起——"Jake 嘲笑他的画是 'creepy garbage'"
6. Ethan 冷静地建议："我们先不要乱指控，但每个人都需要说明昨晚在哪里"——实际在引导怀疑方向

**章末钩子**：Dylan 说不出自己昨晚去了哪里。他低着头，拳头攥紧。沉默比任何话语都更像一份认罪书。

**创作备注**：
- 线索操作：植入 C01（窗锁划痕），激活 H01（Dylan 嫌疑）
- 嫌疑指向：Dylan ★★★★★
- 读者此刻推理状态："Dylan 最可疑，但密室怎么解释？如果他能进去，为什么门窗还是锁着的？"
- 关键技法：**情感遮蔽**——C01 藏在发现尸体的高情绪密度段落中

### Ch4 · 猜忌（Suspicion）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | Lodge 各处（Nora 独自调查路线）|
| 时间 | Day 2 下午 → 傍晚 |
| 核心功能 | 线索收集 · 错误假设固化 · 群体裂痕加深 |
| 字数目标 | ~4,000 字 |
| 张力类型 | 🟡🔴（中→高） |

**核心事件**：
1. 群体分裂为两派——"Dylan 有罪派"（Amber 领头）vs "证据不足派"（Sophie 倾向）。Ethan 扮演调解人
2. Nora 独自重返密室调查。透过窗户向外看——石檐上的灰尘有被扰动的痕迹，混在暴雨景色描写中（**C02——列举遮蔽**）
3. 注意到 Ethan 手指上有细微擦伤。Ethan 笑着说"搬行李时刮到的"（**S01**）
4. Nora 在速写本上画下房间布局、窗户、走廊——**回忆起一个不对劲的细节**：窗户插销虽然锁着，但似乎不在原来的角度上
5. Amber 的反应过度——不仅害怕，更像是心虚。她和 Jake 之间似乎有不愿公开的秘密
6. Ethan 在小组讨论中巧妙地反复提起 Dylan 的可疑之处，同时用"我不是在指控任何人"包装自己

**章末钩子**：Nora 在速写本上画完窗锁的特写。铅笔停在纸面上。有什么不对——但她说不清楚是什么。走廊那头传来 Amber 压低声音的争吵。

**创作备注**：
- 线索操作：植入 C02（石檐灰尘）、S01（Ethan 手伤），强化 H01
- 嫌疑指向：Dylan ★★★★★（峰值），Amber ★★★（异常反应）
- 读者此刻推理状态："Dylan 最可疑，但 Amber 在隐瞒什么？密室还是说不通"
- 关键技法：**碎片化遮蔽**——C02 藏在环境描写中；**首因效应持续**——C03 的"可靠"印象让读者不怀疑 Ethan

### Ch5 · 分裂（The Split）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | 公共大厅 → 各自房间 |
| 时间 | Day 2 夜 → Day 3 凌晨 |
| 核心功能 | 群体瓦解 · 反主题达到顶峰 · 第二次杀人 |
| 字数目标 | ~3,500 字 |
| 张力类型 | 🔴🔴（高→极高） |

**核心事件**：
1. 群体激烈争吵——是否应该把 Dylan 隔离关押。Dylan 绝望但拒绝解释行踪（保护与 Sophie 的秘密）
2. **Ethan 提出"大家分开锁好门"的方案**——表面是保护（"各自反锁最安全"），实质是隔离（为第二次杀人创造条件）
3. Nora 低头时注意到 Ethan 鞋上有灰白色粉末（**S02——石檐材质**），但没有深想
4. C04 累积：Nora 翻看速写本——暗中标注了每次超自然现象发生时各人的位置。模式正在浮现，但还不清晰
5. Amber 在分散前拉住 Nora 的袖子，欲言又止："There's something you should know about Jake and—" 被 Ethan 打断："大家快回房间，锁好门"
6. **反主题生效**：所有人分散、隔离、互不信任——正中凶手下怀

**章末钩子**：深夜两点。暴雨敲窗。Nora 从浅眠中惊醒——隔壁 Amber 的房间传来一声闷响。然后是寂静。Nora 在黑暗中屏住呼吸，告诉自己这是雷声。但她知道那不是。

**创作备注**：
- 线索操作：植入 S02（鞋上灰尘），C04 模式累积
- 嫌疑指向：Dylan ★★★★，Amber ★★★（短暂嫌疑期——她知道什么？）
- 读者此刻推理状态："分散是个好主意吗？Amber 要说什么？"
- 关键时刻：Amber 被打断——这是 Ethan 最明显的一次"控制叙事"行为，但包装成关心
- 反主题高峰：信任瓦解 → 分散隔离 → 凶手得手

### Ch6 · 二杀（Second Death）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | Amber 的房间 → 公共大厅 |
| 时间 | Day 3 清晨 |
| 核心功能 | **中点逆转** · 红鲱鱼消解 · 嫌疑方向翻转 |
| 字数目标 | ~4,000 字 |
| 张力类型 | 🔴（高） |

**核心事件**：
1. 清晨没有人敢出门。Nora 鼓起勇气敲 Amber 的门。没有回应。推开——Amber 死了
2. **不是密室**——Amber 的门没有反锁。凶手是在"大家分散回房"的混乱中与她独处后动手的
3. Sophie 主动站出来："Dylan 昨晚在我房间。一直都在。"——秘密恋情曝光（**H01 消解**）
4. Dylan 被彻底洗清。嫌疑真空——"如果不是 Dylan，那是谁？"
5. **中点认知翻转**：这不是超自然事件，不是冲动杀人——这是有预谋的连环杀人。凶手就在剩余的人中间
6. Nora 在 Jake 手机上发现与 Amber 的旧短信："We handled the Mia thing. Nobody's gonna find out."
7. Ethan 依然冷静得不正常——**C03 强化**。但这一次，他的冷静不再令人安心，而是令人不安

**章末钩子**：四个人坐在大厅里。外面暴雨如注。Nora 看着每一张脸——Dylan 惊魂未定，Sophie 紧握他的手，Ethan 一言不发地望着窗外。凶手就在这个房间里。而 Nora 不知道是谁。

**创作备注**：
- 线索操作：消解 H01（Dylan 洗清），强化 C03（Ethan 的异常冷静）
- 嫌疑指向：Dylan ★★↓（洗清），Ethan ★★★↑（开始升高——"太冷静了"）
- 读者此刻推理状态："Dylan 不是凶手。Mia 是谁？Ethan 是不是太镇定了？"
- 关键翻转：
  - 信息层：从"超自然/Dylan"翻转为"有预谋的连环杀人"
  - 情感层：受害者不再纯粹无辜——"Mia thing" 引入道德灰色地带
  - 嫌疑层：真空状态激发读者重新审视所有人

### Ch7 · 黑夜（Dark Night of the Soul）

| 项目 | 内容 |

### Ch8 · 揭示（Revelation）

| 项目 | 内容 |
|------|------|
| POV | Nora Hartley |
| 地点 | Lodge 二楼走廊 → 公共大厅 |
| 时间 | Day 3 深夜 → Day 4 黎明 |
| 核心功能 | 真相揭示（机制+动机）· 情感高潮 · 主题升华 · 余波 |
| 字数目标 | ~4,500 字 |
| 张力类型 | 🔴🔴🔴🟢（极高→余波） |

**核心事件**：

**一、对峙（揭示前）**
1. Nora 冲向 Ethan 的房间——发现 Sophie 在那里。Ethan 正在平静地和她说话。气氛不对
2. Nora 站在门口："Ethan，是你干的。"
3. Nora 的旁观者面具彻底脱落——她第一次在所有人面前主动站出来指控

**二、推理展示（机制揭示——"怎么做到的"）**
4. Nora 展示推理链：
   - "你去年来过这个 Lodge。你知道二楼窗户外面有石质檐台"
   - "你沿着石檐从自己的窗户爬到 Jake 的窗户外面"
   - "窗户的铁插销因为年久磨损，可以从外面用薄铁片拨开"
   - "你进去杀了 Jake，然后从外面把窗锁推回去"
   - "你鞋上的灰尘是石檐上的——Sophie 注意到了"
   - "每次'超自然现象'发生时你都不在场——因为你就是制造它们的人"

**三、自白（动机揭示——"为什么"）**
5. Ethan 不逃跑、不否认。他坐下来，第一次摘下了那个温暖的笑容
6. 他讲述 Mia Lawson 的故事——
   - 从小一起长大的发小。世界上最善良的人
   - Jake 的欺凌、Amber 的谣言、学校的掩盖
   - 一年前，Mia 在家中自杀未遂。送医后存活，但精神崩溃
   - Ethan 每周去疗养院探望。Mia 已经认不出他了
7. "Do you even remember her?"——这句话刺穿了每个人

**四、情感落点（主题升华）**
8. Sophie 哭了——她知道 Jake 做过什么，但她选择了沉默
9. Nora 面对自己的愧疚——她在图书馆看到过 Mia 被孤立。她也什么都没做
10. 主题完整论证：恐惧让 Ethan 害怕 Mia 被遗忘，驱使他复仇；恐惧让群体互相怀疑，给了他可乘之机。但 Nora 选择了信任和行动——打破了这个循环

**五、余波**
11. 暴雨停了。第一缕晨光透过窗户照进来
12. 远处传来救援车的声音
13. 收尾意象：来时六个人的喧闹，走时四个人的沉默。Nora 的速写本翻到了新的一页——她开始画一个女孩的肖像。Mia Lawson。这一次，她选择记住。

**创作备注**：
- 线索操作：全线索回溯，石檐路径完整重现，诡计机制闭环
- 嫌疑指向：Ethan 确认
- 读者揭示后情感：心碎型——"怎么会是他？但我理解他为什么这么做。"
- 揭示双层结构：
  1. **机制层**：石檐攀越 + 撬窗重锁（解谜满足）
  2. **动机层**：Mia 的故事（情感冲击）
- 回看测试要点全部生效（参见 trick-design.md 第七节）
